A set is a collection of unique elements, it can be denoted as S = {1,2,3 , ...}.
A group is a set that has an operation such as adding , multiplying etc that follows certain rules known as axioms
A group most follow 4 axioms which are:
  • Closure : if we apply the operation onto any 2 numbers, then we must get a number within that set
  • Associativity : it doesnt matter where we group the values together e.g. + is considered Associative as (7 + 2) + 3 is the same as 7 + (2 + 3)
